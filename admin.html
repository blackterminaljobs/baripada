🎯 Telecaller Target System
Level 1: 0–2 unique admissions. Each converted admission receives the Level 1 rate.
Level 2: 3–5 unique admissions. Each converted admission receives the Level 2 rate.
Level 3: 6+ unique admissions. Each converted admission receives the Level 3 rate.

Visits do not generate incentive. Only unique current-month Converted admissions are used for Telecaller admission earning.
The Telecaller page automatically reads these rates from the Admin payment settings.

Payment Rules

Current system calculation rules

Coordinator:
Total Payable = Base Salary + (Unique Visited Students × Visit Incentive) + (Unique Converted Students × Admission Incentive)

Telecaller:
Total Payable = Base Salary + (Unique Converted Admissions × Active Level Admission Rate)

Telecaller visits have ₹0 reward.
Duplicate mobile numbers are counted only once within the same incentive category.
Only current-month performance is used.
Raw inquiries do not generate incentive.
